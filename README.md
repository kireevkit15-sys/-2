# GeoTrace — учебный реестр геохимических проб

Небольшое веб-приложение на русском языке: реестр, автоматическая постоянная нумерация, карточки проб, QR-этикетки, последовательные статусы, история, лабораторные результаты и CSV для Excel/QGIS. Интерфейс адаптируется к телефону. Данные хранятся на компьютере в SQLite, а не в памяти браузера. QR генерируются локально без сторонних сервисов.

## Запуск на Windows

1. Установите Python 3.10 или новее с python.org (с Python Launcher).
2. Распакуйте архив в отдельную папку. Запустите `start.bat`. Библиотеки включены в папку `vendor`; после установки Python интернет для запуска не нужен.
3. Оставьте окно сервера открытым. На компьютере откройте `http://localhost:8000`.
4. Нажмите «Загрузить учебный набор» или создайте свою первую пробу. Набор из 8 проб вымышленный; он доступен только в пустой базе.

Повторный запуск без интернета после установки: `.venv\Scripts\python.exe app.py --host 0.0.0.0`.

## Телефон и настоящие QR-коды

1. Подключите телефон и компьютер к одной доверенной Wi-Fi-сети. Гостевые сети могут блокировать связь устройств.
2. В командной строке Windows выполните `ipconfig`. Найдите IPv4-адрес активного Wi-Fi, например `192.168.1.10`.
3. На телефоне откройте `http://192.168.1.10:8000`. Если Windows спросит о брандмауэре, разрешите Python для частной сети. Не отключайте брандмауэр целиком. Не настраивайте проброс порта на роутере.
4. В поле «Адрес приложения для QR-кодов» на компьютере впишите этот же адрес. Сначала проверьте его на телефоне, затем печатайте этикетки. `localhost` в QR-коде не подходит для другого устройства.
5. Откройте карточку → «Печать этикетки», либо «Печать этикеток» в меню для всех проб. В диалоге печати можно выбрать «Сохранить как PDF»; отключите колонтитулы браузера, используйте масштаб 100%. Сначала проверьте одну этикетку камерой телефона.
6. Наклейте QR на пакет. Обычная камера телефона открывает карточку по ссылке. Устанавливать приложение на телефон не нужно.

Адрес компьютера должен оставаться прежним: при смене IP старые QR-ссылки перестанут работать. Для постоянной эксплуатации нужен постоянный адрес или HTTPS-домен. Компьютер и сервер должны работать во время показа. Офлайн-синхронизация и работа из другой сети в эту версию не входят. Сканирование камерой реального телефона проверяется пользователем на месте.

## Сценарий показа преподавателю (3–5 минут)

1. Добавить пробу: участок, профиль, точка, материал, исполнитель, координаты WGS84 и описание. Номер вида `GC-2026-00009` присваивается базой автоматически; год берётся из даты создания.
2. Распечатать этикетку и открыть карточку телефоном.
3. На компьютере отметить отбор, передачу в лабораторию, начало анализа.
4. Внести, например, Cu = 42.5 мг/кг, метод ICP-MS. Это демонстрационное значение, не результат настоящего анализа.
5. Добавить другие элементы или значение ниже предела обнаружения через квалификатор «<». Пустое значение не заменяется нулём.
6. Завершить анализ. Обновить карточку на телефоне — статус и результаты изменились, QR остался прежним.
7. Показать историю этапов и экспорт CSV (UTF-8 с BOM, разделитель `;`). Координаты можно импортировать в QGIS как точки EPSG:4326.

Номер пробы отделён от профиля/точки: повторный отбор в той же точке получает новый номер. Для этой учебной версии результаты добавляются только во время анализа; после завершения карточка результатов закрыта для редактирования. Лаборатория не подключена автоматически — результаты вносятся вручную.

## Linux / macOS

```sh
cd /путь/к/GeoTrace
python3 -m venv .venv
.venv/bin/python -m pip install --no-index --find-links vendor -r requirements.txt
.venv/bin/python app.py --host 0.0.0.0 --port 8000
```

Для доступа только с этого компьютера опустите `--host 0.0.0.0`.

## Хранение, ограничения и проверка

База создаётся автоматически: `data/samples.sqlite3`. Не удаляйте её после печати QR. Для резервной копии остановите сервер (`Ctrl+C`) и скопируйте файл. Восстановление: при остановленном сервере верните копию в ту же папку. Переменная `GEOCHEM_DB` позволяет выбрать другую базу, например для тестов.

Это учебный прототип без входа и ролей: любой человек, имеющий сетевой доступ, может создавать пробы и менять разрешённые статусы. Не публикуйте этот сервер в интернете и не вводите конфиденциальные реальные данные. Для промышленной версии нужны аутентификация, права геолога/лаборатории, журнал исправлений, резервное копирование, HTTPS и валидация лабораторных импортов. Условные точки учебного набора не являются проектом геохимической съёмки.

```sh
.venv/bin/python -m unittest discover -s tests -v
```

## Выполненные проверки

В облачной Linux-среде прошли три автоматизированных API-теста (жизненный цикл и сохранение анализа, параллельная нумерация и координаты, QR и ошибки). В Chromium проверены создание пробы, все этапы, ввод анализа, повторное открытие, поиск, фильтры, мобильная ширина 390 px и печать. SVG-код прочитан независимым декодером ZXing, ссылка совпала с карточкой. Windows-файл запуска и сканирование физическим телефоном в вашей сети здесь не проверялись. Скриншоты — в `artifacts`.
